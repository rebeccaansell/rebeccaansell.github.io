As machine learning models demand larger training datasets, synthetic data generation offers a powerful solution for augmenting limited real-world data. This hands-on workshop teaches participants to generate augmented data using LLM-based techniques and rigorously evaluate its effectiveness.

Through interactive coding exercises, attendees will implement data generation methods including prompting strategies, and controlled generation. We focus on the critical evaluation challenge: determining whether augmented data improves model performance while maintaining distributional alignment and avoiding artifacts. Participants explore evaluation metrics including distribution similarity measures, downstream task benchmarking, and human evaluation protocols.

Attendees leave with practical experience building augmentation pipelines, implementing evaluation frameworks, and making informed decisions about incorporating generated data into ML workflows.

**Intended Audience**: ML researchers and practitioners with basic Python experience working with limited labeled datasets.
